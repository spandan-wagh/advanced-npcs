# Advanced NPCs Roadmap

This roadmap describes the current development direction for Advanced NPCs. Priorities may change based on testing, technical requirements and user feedback.

## Version 1.0 — First Public Release

* [x] Runtime and Editor module separation
* [x] Configurable Intent system
* [x] Intent Sets and per-NPC overrides
* [x] Additional Intents
* [x] Intent priorities, interruptions and cooldowns
* [x] One Shot and Continuous Intent behaviour
* [x] Manual Intent activation
* [x] Built-in condition types
* [x] Condition groups
* [x] Capability system
* [x] Patrol, follow and wander behaviours
* [x] Movement modifiers
* [x] Custom Unreal Editor interfaces
* [x] Complete user documentation
* [x] Final runtime testing
* [x] Final editor testing
* [x] Packaging validation
* [x] Clean-project installation testing
* [x] Demonstration project
* [ ] Fab approval
* [ ] Public release

## Future Exploration

The following ideas are being considered but are not guaranteed release commitments:

* Additional built-in condition types
* Expanded movement behaviours
* Improved runtime debugging tools
* NPC state and Intent visualization
* Additional editor workflow improvements
* More example NPC configurations
* Performance profiling for larger NPC populations
* Community-requested integrations

## Feedback

Developers can suggest improvements through the repository’s Issues page:

[Submit feedback or a feature request](https://github.com/spandan-wagh/advanced-npcs/issues)

Feature priorities will be based on usefulness, technical feasibility, compatibility and demand.
