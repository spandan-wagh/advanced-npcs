# Advanced NPCs Support

Thank you for using Advanced NPCs.

Advanced NPCs is currently being prepared for its first public release for Unreal Engine 5.7.

## Before Reporting a Problem

Before opening an issue:

1. Confirm that you are using a supported Unreal Engine version.
2. Confirm that Advanced NPCs is enabled in your project.
3. Review the included documentation.
4. Restart Unreal Editor and test the problem again.
5. If possible, reproduce the problem in a clean Unreal Engine project.

## Report a Bug

Report bugs through the GitHub Issues page:

[Open a new issue](https://github.com/spandan-wagh/advanced-npcs/issues/new)

Please include:

* Advanced NPCs version
* Unreal Engine version
* Operating system
* Clear steps to reproduce the problem
* Expected result
* Actual result
* Relevant screenshots, videos or log messages
* Whether the problem also occurs in a clean project

## Feature Requests

Feature requests may also be submitted through GitHub Issues.

Please describe:

* The problem you are trying to solve
* Your proposed workflow
* Why the feature would be useful to other Unreal Engine developers
* Any alternative solution you currently use

## Security and Privacy

Do not publish:

* Passwords or API keys
* Personal information
* Complete project files containing private content
* Advanced NPCs source files
* Licensed third-party assets
* Confidential crash logs

Remove sensitive information before attaching logs or screenshots.

## Support Scope

Support covers problems directly related to installing, configuring and using Advanced NPCs.

Support does not guarantee assistance with unrelated Unreal Engine problems, custom game development, third-party plugins or third-party assets.

## Documentation

Complete documentation will be linked here when Advanced NPCs is publicly released.

## Response Times

Issues will be reviewed when possible. Response and resolution times may vary depending on the complexity of the problem.
